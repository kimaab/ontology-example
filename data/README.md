# 인사·복지 AI 임시 수집 데이터

> ※ 이 폴더의 데이터는 모두 **학습용 가상 데이터**입니다. 실제 한국석유공사 규정이나 인사정보가 아닙니다.
> 프로젝트가 시작되면 아래 "실제 수집 대상"의 자료로 바꿉니다.
> 기준일: 2026-11-12 (근속연수 계산 기준)

## 폴더 구성

```
data/
├── regulations/   규정 문서 (실제로는 사규관리시스템의 PDF·HWP)
├── manuals/       업무 매뉴얼 (실제로는 그룹웨어 도움말)
└── erp/           인사정보·코드표 (실제로는 ERP 테이블. CSV는 PostgreSQL COPY로 바로 적재 가능)
```

## 임시 직원 데이터의 시험용 케이스

`employees.csv`에는 CQ를 시험할 수 있도록 다음 직원을 일부러 넣었습니다.

| 케이스 | 사번 | 시험하는 것 |
|---|---|---|
| 근속 1년 미만 (0.3, 0.6, 0.9년) | E02001 ~ E02003 | CQ1 1년 미만 규칙, CQ4 자격 미달 |
| 근속 만 3년 직전 / 정확히 만 3년 | E02006 / E02007 | CQ1 경계값 (15일 → 16일) |
| 징계 기간 중 | E02008, E02018 | CQ4 제외 대상 |
| 휴직 중 | E02009, E02014 | CQ4 제외 대상, 생일 축하금 제외 |
| 근속 21년 이상 | E02025 ~ E02030 | CQ1 상한 25일 |
| 1~3급 / 4~6급 | 전체 | CQ4 직급별 지원 한도 |
